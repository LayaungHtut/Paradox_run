## What automated checks cannot establish

- **Taste:** whether the audio mix, music and effects _sound_ good. The tests only prove that every sound
  produces clean signal.
- **Real devices:** everything was tested in desktop Chromium and Chromium's phone emulation. It has
  not been run on a physical iPhone or Android phone.
- **Human understanding:** the code is structured and commented so that a developer can review it,
  but no human has yet signed off on having done so.
